# المركز الفني للصيانة — دليل النشر

هذا المشروع واجهة عربية متجاوبة مع قاعدة بيانات Supabase وتسجيل دخول آمن للمدير عبر Supabase Auth.

## قبل البدء
- أنشئ مشروعًا مجانيًا في Supabase.
- من SQL Editor شغّل كامل الملف `supabase/schema.sql`.
- من Authentication > Users أنشئ مستخدمًا ببريد إلكتروني وكلمة مرور قوية يختارهما صاحب المحل.
- بعد إنشاء المستخدم، انسخ User UID ثم نفّذ في SQL Editor:
  ```sql
  insert into public.admin_users(user_id)
  values ('ضع-هنا-معرّف-المستخدم-UID');
  ```
- من Project Settings > API انسخ Project URL و`anon` / publishable key. لا تستخدم `service_role` أبدًا في الموقع أو المتصفح.

## تشغيل محلي
1. ثبّت Node.js إصدار LTS.
2. انسخ `.env.example` إلى `.env` واملأ القيم:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
3. نفّذ:
   ```bash
   npm install
   npm run dev
   ```

## النشر المجاني على Netlify (مناسب لموقع المحل)
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. أنشئ حسابًا مجانيًا في Netlify واربطه بمستودع GitHub.
3. إعدادات البناء: Build command = `npm run build`، ومجلد النشر = `dist`.
4. أضف متغيري البيئة `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في إعدادات الموقع.
5. اضغط Deploy. سيمنحك Netlify رابطًا مجانيًا ينتهي بـ `netlify.app` ويمكنك تغيير الاسم المتاح من إعدادات الموقع.
6. الخطة المجانية في Netlify تسمح بالاستخدام التجاري ضمن حدود الرصيد الشهري؛ راجع صفحة الأسعار قبل النشر إذا زاد الاستخدام.

## دخول لوحة الإدارة
- افتح الموقع ثم «دخول الإدارة».
- استخدم البريد وكلمة المرور اللذين أنشأتهما في Supabase.
- لن يتم السماح بإدارة المنتجات إلا للمستخدم الذي أُضيف UID الخاص به إلى `admin_users`.
- من اللوحة يمكنك إضافة المنتجات وتعديل الأسعار والصور وحذف المنتجات وتعديل بيانات الاتصال والعنوان.

## ملاحظات أمان مهمة
- لا تضع `service_role` أو أي مفتاح سري في ملفات `VITE_*` أو GitHub.
- لا ترسل كلمة المرور في المحادثة. أنشئها مباشرة في Supabase.
- حماية التعديل تعتمد على Supabase Auth وRLS في قاعدة البيانات، وليس على إخفاء زر الإدارة فقط.
- صور المنتجات العامة يمكن للزوار مشاهدتها، لكن الرفع والتعديل والحذف محصور بالمدير.
- النسخة الحالية تتيح إدارة منتجات تغيير الليدات وبيانات المحل. الضمانات والخدمات الإضافية ثابتة في الواجهة وتحتاج توسيعًا منفصلًا إذا أردت تحريرها من اللوحة.
- الأسعار نطاقات استرشادية كما زوّدنا بها صاحب المحل؛ يجب تأكيد السعر النهائي بعد الفحص.
